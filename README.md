# Expense Tracker

A simple and interactive Expense Tracker application built with **React, TypeScript, and Bootstrap**. This project allows users to manage their daily expenses, organize spending by category, and keep track of their finances.

## 🚀 Features

- **Add Expenses** – Record expenses with a description, amount, and category.
- **View Expenses** – Display all recorded expenses in an organized table.
- **Filter Expenses** – Filter expenses by category.
- **Delete Expenses** – Remove unwanted expense records.
- **Form Validation** – Validate user inputs using React Hook Form and Zod.
- **Responsive Design** – Built with Bootstrap for a clean, responsive interface.

## 🛠️ Technologies Used

- **React** – Frontend UI library
- **TypeScript** – Type-safe JavaScript
- **Vite** – Development and build tool
- **Bootstrap** – Responsive styling
- **React Hook Form** – Form handling
- **Zod** – Schema validation

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jangwalia/Expense-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd expense-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
